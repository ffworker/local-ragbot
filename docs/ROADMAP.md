# Roadmap

## Phase 1: Text RAG

- Local file ingestion
- Local index
- RAG-only answers
- Refuse unknown questions
- Tiny HTTP UI

## Phase 2: Better Local Models

- Optional Ollama generation with `llama3.2:1b`
- Replace hashing retrieval with small multilingual embeddings
- Add source previews and confidence thresholds

## Phase 3: Voice

- STT with `whisper.cpp` tiny/base
- TTS with Piper
- Push-to-talk first

## Phase 4: Call Mode

- Browser WebRTC call
- Later SIP or phone provider integration
- Per-user role and data-source permissions
